FredAPI.AbstractFredEndpointModel — Type
AbstractFredEndpointModel

Abstract base type for all FRED (Federal Reserve Economic Data) API endpoint models. Each subtype represents one endpoint of the API and holds the data needed to call it.

source
FredAPI.api — Function
api(endpoint::Type{T}, request_url::String;
    handler::Function = _default_handler_process_fred_response) where T <: AbstractFredEndpointModel

Make an HTTP GET request to a FRED endpoint, and process the response.

Arguments

  • endpoint::Type{T}: the endpoint model type that identifies the response to process.
  • request_url::String: the complete URL that url(...) returned. The URL holds the API key, so do not print it.
  • handler::Function: the function that receives the endpoint model type and the response body as a String. The default handler parses the JSON text into a dictionary.

Returns

  • The result of the handler. The default handler returns a dictionary.

Throws

  • ArgumentError: when the URL does not start with http:// or https://, when the connection fails, or when the status code of the response is not 200. The message gives the status code and FRED's description of the problem when there is one. The messages never show the URL or the API key.

Example

request_url = url(baseurl, MyFredSeriesEndpointModel(apikey = apikey, series_id = "GNPCA"));
result = api(MyFredSeriesEndpointModel, request_url);

FredAPI.read_configuration — Function
read_configuration(path::String) -> Dict{String,Any}

Read the configuration file, and check that it holds a FRED API key.

The file is written in the TOML format. Its [connection] section has two entries: apikey, your FRED API key, and baseurl, the base URL of the FRED API.

Arguments

  • path::String: the path to the configuration file, e.g., joinpath("conf", "Configuration.toml").

Returns

  • Dict{String,Any}: the [connection] section as a dictionary with the keys "apikey" and "baseurl".

Throws

  • ArgumentError: when the file does not exist, when the file is not valid TOML, when an entry is not there, or when the key is not 32 characters long. The messages never show the contents of the file. The message for a missing file names the absolute path that it checked.

Example

connection = read_configuration(joinpath("conf", "Configuration.toml"));
baseurl = connection["baseurl"];
apikey = connection["apikey"];

FredAPI.hidekey — Function
hidekey(url::String, apikey::String) -> String

Return a copy of a URL that shows the text <your key> in place of the API key. Use this copy to print or share a URL. Use the original URL to call FRED.

Arguments

  • url::String: the URL string that a url(...) method returned.
  • apikey::String: your FRED API key.

Returns

  • String: the URL with the key replaced, e.g., "https://api.stlouisfed.org/fred/series?series_id=DHHNGSP&api_key=<your key>&file_type=json".

Example

safe_url = hidekey(request_url, apikey);
println(safe_url);
