Maps

The Maps API returns data by region, such as the value of one quantity in each state. A region type names a kind of region, such as "state". A series group is the set of regional series that measure one quantity across the regions of one region type, such as series group 882, the per capita personal income of each state. The geofred/shapes/file and geofred/series/group endpoints have no table handler, so their examples return a dictionary.

geofred/shapes/file

The geofred/shapes/file endpoint returns the boundaries of the regions of one region type, such as "state", in the GeoJSON format.

model = MyFredMapsShapesEndpointModel(apikey = apikey, shape = "state");
request_url = url(baseurl, model);
result = api(MyFredMapsShapesEndpointModel, request_url);
FredAPI.MyFredMapsShapesEndpointModel — Type
mutable struct MyFredMapsShapesEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED geofred/shapes/file endpoint, described at https://fred.stlouisfed.org/docs/api/geofred/shapes.html. This endpoint returns the boundaries of the regions of one shape type, as a GeoJSON FeatureCollection. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • shape::String: the type of region to return the boundaries of: "bea", "msa", "frb", "necta", "state", "country", "county", "censusregion", or "censusdivision". FRED requires this field.

Constructors

  • MyFredMapsShapesEndpointModel(; apikey::String = "", shape::String = ""): returns a new MyFredMapsShapesEndpointModel instance. Every argument is a keyword argument.

FredAPI.url — Method
url(base::String, model::MyFredMapsShapesEndpointModel) -> String

Build the URL string for the geofred/shapes/file endpoint of the FRED API. An HTTP GET call to this URL calls the endpoint with the parameters that the model holds. This endpoint returns the boundaries of the regions of one shape type, as GeoJSON. The URL lists the shape parameter, then the API key. This endpoint takes no format parameter, so the URL adds none. A field at its empty value stays out of the URL.

Arguments

  • base::String: the base URL of the FRED API, i.e., "https://api.stlouisfed.org".
  • model::MyFredMapsShapesEndpointModel: the endpoint model that holds the API key and the parameters of the call.

Returns

  • String: the complete URL string. The URL holds the API key, so do not print it or share it.

Throws

  • This function does not throw an error.

Example

model = MyFredMapsShapesEndpointModel(apikey = apikey, shape = "state");
request_url = url("https://api.stlouisfed.org", model);

geofred/series/group

The geofred/series/group endpoint returns the series group of one regional series, with its title, region type, units, frequency, and first and last dates. The example asks for the series group of "SMU56000000500000001a", the number of employees in total private industries in Wyoming.

model = MyFredMapsSeriesGroupEndpointModel(apikey = apikey, series_id = "SMU56000000500000001a");
request_url = url(baseurl, model);
result = api(MyFredMapsSeriesGroupEndpointModel, request_url);
FredAPI.MyFredMapsSeriesGroupEndpointModel — Type
mutable struct MyFredMapsSeriesGroupEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED geofred/series/group endpoint, described at https://fred.stlouisfed.org/docs/api/geofred/series_group.html. This endpoint returns the meta information of the series group that a regional series belongs to. The response holds the title, the region type, the series group, the season, the units, the frequency, and the first and last dates of the group. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • series_id::String: the identifier of a FRED series that has regional data, e.g., "SMU56000000500000001a". FRED requires this field.

Constructors

geofred/series/data

The geofred/series/data endpoint returns the value of each series in the series group of one regional series. The example asks for the per capita personal income of each state on 2012-01-01, from the series group of "WIPCPI", the per capita personal income of Wisconsin.

model = MyFredMapsSeriesDataEndpointModel(apikey = apikey, series_id = "WIPCPI", date = "2012-01-01");
request_url = url(baseurl, model);
table = api(MyFredMapsSeriesDataEndpointModel, request_url; handler = process_maps_series_data_response_dataframe);
FredAPI.MyFredMapsSeriesDataEndpointModel — Type
mutable struct MyFredMapsSeriesDataEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED geofred/series/data endpoint, described at https://fred.stlouisfed.org/docs/api/geofred/series_data.html. This endpoint returns the regional data of one series, i.e., the value of the series in each region, on one date or over a range of dates. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • series_id::String: the identifier of a FRED series that has regional data, e.g., "WIPCPI". FRED requires this field.
  • date::String: the date of the data, written as "YYYY-MM-DD". When the field is empty, FRED uses the most recent date.
  • start_date::String: the first date of a range of dates, written as "YYYY-MM-DD". Set this field together with date, which then holds the last date of the range. When the field is empty, FRED returns the data of one date.

Constructors

  • MyFredMapsSeriesDataEndpointModel(; apikey::String = "", series_id::String = "", date::String = "", start_date::String = ""): returns a new MyFredMapsSeriesDataEndpointModel instance. Every argument is a keyword argument.

geofred/regional/data

The geofred/regional/data endpoint returns the value of one series group in each region of one region type. The example asks for series group 882 on 2013-01-01, as annual ("a") values in dollars that are not seasonally adjusted ("NSA").

model = MyFredMapsRegionalDataEndpointModel(apikey = apikey, series_group = "882", region_type = "state",
    date = "2013-01-01", season = "NSA", units = "Dollars", frequency = "a");
request_url = url(baseurl, model);
table = api(MyFredMapsRegionalDataEndpointModel, request_url; handler = process_maps_regional_data_response_dataframe);
FredAPI.MyFredMapsRegionalDataEndpointModel — Type
mutable struct MyFredMapsRegionalDataEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED geofred/regional/data endpoint, described at https://fred.stlouisfed.org/docs/api/geofred/regional_data.html. This endpoint returns the regional data of one series group, i.e., the value of the group in each region of one region type. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • series_group::String: the identifier of the series group, e.g., "882". FRED requires this field.
  • region_type::String: the type of region: "bea", "msa", "frb", "necta", "state", "country", "county", or "censusregion". FRED requires this field.
  • date::String: the date of the data, written as "YYYY-MM-DD". FRED requires this field.
  • start_date::String: the first date of a range of dates, written as "YYYY-MM-DD". Set this field together with date, which then holds the last date of the range. When the field is empty, FRED returns the data of one date.
  • season::String: the seasonal adjustment of the data: "SA", "NSA", "SSA", "SAAR", or "NSAAR". FRED requires this field.
  • units::String: the units of the data as text, e.g., "Dollars". FRED requires this field.
  • transformation::String: the transformation of the data: "lin" (levels), "chg", "ch1", "pch", "pc1", "pca", "cch", "cca", or "log". When the field is empty, FRED uses "lin".
  • frequency::String: the frequency of the data: "d", "w", "bw", "m", "q", "sa", "a", "wef", "weth", "wew", "wetu", "wem", "wesu", "wesa", "bwew", or "bwem".
  • aggregation_method::String: how FRED aggregates the data when it lowers the frequency: "avg" (average), "sum", or "eop" (end of period). When the field is empty, FRED uses "avg".

Constructors

Every argument is a keyword argument.
