fred/tags

The fred/tags endpoint returns every tag, with the number of series that carry the tag.

model = MyFredTagsEndpointModel(apikey = apikey, limit = 3);
request_url = url(baseurl, model);
table = api(MyFredTagsEndpointModel, request_url; handler = process_tags_response_dataframe);
FredAPI.MyFredTagsEndpointModel — Type
mutable struct MyFredTagsEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED fred/tags endpoint, described at https://fred.stlouisfed.org/docs/api/fred/tags.html. This endpoint returns the tags of FRED. A tag is a word that describes a series, e.g., its frequency or its geography. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • realtime_start::String: the first day of the real-time period, written as "YYYY-MM-DD". The real-time period selects the vintage of the data that we see, i.e., the data as it stood on those days. When the field is empty, FRED uses today's date.
  • realtime_end::String: the last day of the real-time period, written as "YYYY-MM-DD". When the field is empty, FRED uses today's date.
  • tag_names::String: the tag names that a series must all have, separated by semicolons, e.g., "slovenia;food". When the field is empty, FRED does not filter by tag.
  • tag_group_id::String: the group of tags to return: "freq" (frequency), "gen" (general or concept), "geo" (geography), "geot" (geography type), "rls" (release), "seas" (seasonal adjustment), "src" (source), or "cc" (citation and copyright). When the field is empty, FRED returns the tags of every group.
  • search_text::String: the words to match against the tag names and the tag notes. When the field is empty, FRED does not filter the tags by text.
  • limit::Int64: the largest number of tags to return, between 1 and 1000. When the field is 0, FRED uses 1000.
  • offset::Int64: the number of results to skip, starting at 0. When the field is 0, FRED skips none.
  • order_by::String: the attribute to sort the results by: "series_count", "popularity", "created", "name", or "group_id". When the field is empty, FRED uses "series_count".
  • sort_order::String: the order of the results: "asc" (ascending) or "desc" (descending). When the field is empty, FRED uses "asc".

Every argument is a keyword argument.

FredAPI.url — Method
url(base::String, model::MyFredTagsEndpointModel) -> String

Build the URL string for the fred/tags endpoint of the FRED API. An HTTP GET call to this URL calls the endpoint with the parameters that the model holds. This endpoint returns the tags of FRED. A tag is a word that describes a series, e.g., its frequency or its geography. The URL lists the parameters in the order of the fields of the model, then the API key, then file_type=json, which asks FRED for JSON text. A field at its empty value stays out of the URL.

Arguments

  • base::String: the base URL of the FRED API, i.e., "https://api.stlouisfed.org".
  • model::MyFredTagsEndpointModel: the endpoint model that holds the API key and the parameters of the call.

Returns

  • String: the complete URL string. The URL holds the API key, so do not print it or share it.

Throws

  • This function does not throw an error.

Example

model = MyFredTagsEndpointModel(apikey = apikey, limit = 3);
request_url = url("https://api.stlouisfed.org", model);

fred/related_tags

The fred/related_tags endpoint selects the series that carry every tag in tag_names, and returns the other tags of those series.

model = MyFredRelatedTagsEndpointModel(apikey = apikey, tag_names = "monetary aggregates;weekly", limit = 3);
request_url = url(baseurl, model);
table = api(MyFredRelatedTagsEndpointModel, request_url; handler = process_tags_response_dataframe);

fred/tags/series
