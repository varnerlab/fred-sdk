FredAPI.MyFredReleasesEndpointModel — Type
mutable struct MyFredReleasesEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED fred/releases endpoint, described at https://fred.stlouisfed.org/docs/api/fred/releases.html. This endpoint returns every release of economic data: its identifier, name, and whether the release is a press release. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • realtime_start::String: the first day of the real-time period, written as "YYYY-MM-DD". The real-time period selects the vintage of the data that we see, i.e., the data as it stood on those days. When the field is empty, FRED uses today's date.
  • realtime_end::String: the last day of the real-time period, written as "YYYY-MM-DD". When the field is empty, FRED uses today's date.
  • limit::Int64: the largest number of releases to return, between 1 and 1000. When the field is 0, FRED uses 1000.
  • offset::Int64: the number of results to skip, starting at 0. When the field is 0, FRED skips none.
  • order_by::String: the attribute to sort the results by: "release_id", "name", "press_release", "realtime_start", or "realtime_end". When the field is empty, FRED uses "release_id".
  • sort_order::String: the order of the results: "asc" (ascending) or "desc" (descending). When the field is empty, FRED uses "asc".

Constructors

  • MyFredReleasesEndpointModel(; apikey::String = "", realtime_start::String = "", realtime_end::String = "", limit::Int64 = 0, offset::Int64 = 0, order_by::String = "", sort_order::String = ""): returns a new MyFredReleasesEndpointModel instance. Every argument is a keyword argument.

mutable struct MyFredReleasesDatesEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED fred/releases/dates endpoint, described at https://fred.stlouisfed.org/docs/api/fred/releases_dates.html. This endpoint returns the release dates of every release of economic data. Each record holds a release identifier, a release name, and a date. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • realtime_start::String: the first day of the real-time period, written as "YYYY-MM-DD". The real-time period selects the release dates that we see. When the field is empty, FRED uses the first day of the current year.
  • realtime_end::String: the last day of the real-time period, written as "YYYY-MM-DD". When the field is empty, FRED uses "9999-12-31".
  • limit::Int64: the largest number of release dates to return, between 1 and 1000. When the field is 0, FRED uses 1000.
  • offset::Int64: the number of results to skip, starting at 0. When the field is 0, FRED skips none.
  • order_by::String: the attribute to sort the results by: "release_date", "release_id", or "release_name". When the field is empty, FRED uses "release_date".
  • sort_order::String: the order of the results: "asc" (ascending) or "desc" (descending). When the field is empty, FRED uses "desc".
  • include_release_dates_with_no_data::Bool: whether to include the release dates that have no data. When the field is false, FRED leaves out those dates, and the parameter stays out of the URL.

Endpoint model for the FRED fred/release/series endpoint, described at https://fred.stlouisfed.org/docs/api/fred/release_series.html. This endpoint returns the economic data series that belong to one release. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • release_id::Int64: the identifier of the release, e.g., 51. FRED requires this field.
  • realtime_start::String: the first day of the real-time period, written as "YYYY-MM-DD". The real-time period selects the vintage of the data that we see, i.e., the data as it stood on those days. When the field is empty, FRED uses today's date.
  • realtime_end::String: the last day of the real-time period, written as "YYYY-MM-DD". When the field is empty, FRED uses today's date.
  • limit::Int64: the largest number of series to return, between 1 and 1000. When the field is 0, FRED uses 1000.
  • offset::Int64: the number of results to skip, starting at 0. When the field is 0, FRED skips none.
  • order_by::String: the attribute to sort the results by: "series_id", "title", "units", "frequency", "seasonal_adjustment", "realtime_start", "realtime_end", "last_updated", "observation_start", "observation_end", "popularity", or "group_popularity".   • sort_order::String: the order of the results: "asc" (ascending) or "desc" (descending). When the field is empty, FRED uses "asc".

  • filter_value::String: the value of the filter_variable attribute to keep, e.g., "Monthly" for the frequency or "Percent" for the units. Set this field together with filter_variable. When the field is empty, FRED does not filter.
  • tag_names::String: the tag names that a series must all have, separated by semicolons, e.g., "income;bea". When the field is empty, FRED does not select by tag.

model = MyFredReleaseRelatedTagsEndpointModel(apikey = apikey, release_id = 86, tag_names = "sa;foreign", limit = 3);

fred/release/tables

The fred/release/tables endpoint returns the elements of the tables of one release, i.e., the sections and series of the tables. The example asks for the elements below element 12886, Personal consumption expenditures, in release 53.

model = MyFredReleaseTablesEndpointModel(apikey = apikey, release_id = 53, element_id = 12886);
request_url = url(baseurl, model);
table = api(MyFredReleaseTablesEndpointModel, request_url; handler = process_release_tables_response_dataframe);
FredAPI.MyFredReleaseTablesEndpointModel — Type
mutable struct MyFredReleaseTablesEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED fred/release/tables endpoint, described at https://fred.stlouisfed.org/docs/api/fred/release_tables.html. This endpoint returns the elements of the table of one release. Each element is a section or a series of the table, and an element can have children. This endpoint takes no real-time parameters. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • release_id::Int64: the identifier of the release, e.g., 53. FRED requires this field.
  • element_id::Int64: the identifier of the element of the table to start from, e.g., 12886. When the field is 0, FRED uses the root element of the release.
  • include_observation_values::Bool: whether to include the observation values. FRED returns values only for the elements that are series. When the field is false, FRED leaves out the values, and the parameter stays out of the URL.
  • observation_date::String: the date of the observation values, written as "YYYY-MM-DD". When the field is empty, FRED uses "9999-12-31", i.e., the latest observation.
