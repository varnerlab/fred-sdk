fred/sources

The fred/sources endpoint returns every source, with its identifier, its name, and its link.

model = MyFredSourcesEndpointModel(apikey = apikey, limit = 3);
request_url = url(baseurl, model);
table = api(MyFredSourcesEndpointModel, request_url; handler = process_sources_response_dataframe);
FredAPI.MyFredSourcesEndpointModel — Type
mutable struct MyFredSourcesEndpointModel <: AbstractFredEndpointModel

Endpoint model for the FRED fred/sources endpoint, described at https://fred.stlouisfed.org/docs/api/fred/sources.html. This endpoint returns every source of economic data: its identifier, name, and, when FRED has them, its link and notes. Every field is at its empty value by default. A field at its empty value ("", 0, or false) stays out of the URL, so FRED applies its own default for that field.

Fields

  • apikey::String: the FRED API key of the client, a 32 character string of lowercase letters and digits.
  • realtime_start::String: the first day of the real-time period, written as "YYYY-MM-DD". The real-time period selects the vintage of the data that we see, i.e., the data as it stood on those days. When the field is empty, FRED uses today's date.
  • realtime_end::String: the last day of the real-time period, written as "YYYY-MM-DD". When the field is empty, FRED uses today's date.
  • limit::Int64: the largest number of sources to return, between 1 and 1000. When the field is 0, FRED uses 1000.
  • offset::Int64: the number of results to skip, starting at 0. When the field is 0, FRED skips none.
  • order_by::String: the attribute to sort the results by: "source_id", "name", "realtime_start", or "realtime_end". When the field is empty, FRED uses "source_id".
  • sort_order::String: the order of the results: "asc" (ascending) or "desc" (descending). When the field is empty, FRED uses "asc".

Constructors

  • MyFredSourcesEndpointModel(; apikey::String = "", realtime_start::String = "", realtime_end::String = "", limit::Int64 = 0, offset::Int64 = 0, order_by::String = "", sort_order::String = ""): returns a new MyFredSourcesEndpointModel instance. Every argument is a keyword argument.

FredAPI.url — Method
url(base::String, model::MyFredSourcesEndpointModel) -> String

Build the URL string for the fred/sources endpoint of the FRED API. An HTTP GET call to this URL calls the endpoint with the parameters that the model holds. This endpoint returns every source of economic data: its identifier, name, and, when FRED has them, its link and notes. The URL lists the parameters in the order of the fields of the model, then the API key, then file_type=json, which asks FRED for JSON text. A field at its empty value stays out of the URL.

Arguments

  • base::String: the base URL of the FRED API, i.e., "https://api.stlouisfed.org".
  • model::MyFredSourcesEndpointModel: the endpoint model that holds the API key and the parameters of the call.

Returns

  • String: the complete URL string. The URL holds the API key, so do not print it or share it.

Throws

  • This function does not throw an error.

Example

model = MyFredSourcesEndpointModel(apikey = apikey, limit = 3);
request_url = url("https://api.stlouisfed.org", model);

model = MyFredSourceEndpointModel(apikey = apikey, source_id = 1);

table = api(MyFredSourceEndpointModel, request_url; handler = process_sources_response_dataframe);

fred/source/releases

The fred/source/releases endpoint returns the releases that one source publishes, such as the first 3 releases of source 1.

model = MyFredSourceReleasesEndpointModel(apikey = apikey, source_id = 1, limit = 3);
request_url = url(baseurl, model);
table = api(MyFredSourceReleasesEndpointModel, request_url; handler = process_releases_response_dataframe);
